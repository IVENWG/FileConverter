# LessMB Converter

## Description

**LessMB Converter** is a simple tool which allows you to convert and compress one or several file(s) using the context menu of windows explorer.

## Features

- Convert and compress files in 2 clicks from Windows Explorer context menu
- Support for image, audio, video, and document formats
- Batch conversion support
- Hardware acceleration (NVIDIA NVENC, AMD AMF)
- Multi-language support

## Supported Formats

- **Images**: png, jpg, gif, ico, bmp, tiff, webp, avif, svg
- **Audio**: mp3, wav, ogg, flac, aac, wma
- **Video**: mp4, avi, mkv, webm, wmv, flv
- **Documents**: pdf

## Setup Development Environment

### Requirements

- Visual Studio 2022
- .NET Framework 4.8
- [Wix 5](http://wixtoolset.org/) (for installer)
